# Este repositorio contiene los archivos de entrada, salida y scripts de análisis desarrollados para el Trabajo de Fin de Máster (TFM). 
# El objetivo del proyecto es procesar y analizar datos genómicos/metagenómicos de muestras históricas de *Bombus pascuorum* utilizando el pipeline DNAharvester (NBIS).
# Estructura del repositorio
.
├── R/                  # Scripts de R para procesamiento de datos, estadística y figuras
└── pipeline/           # Archivos del pipeline e instrucciones para MobaXterm
    ├── input/          # Archivos de entrada para el pipeline (metadatos, tablas de muestras, etc.)
    └── output/         # Resultados procesados y generados por el pipeline
        ├── mapping/
        └── microbial_screening/
